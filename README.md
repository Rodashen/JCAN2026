# JCAN2026

JCAN Korean Language Center website with EPS-TOPIK CBT and UBT practice exams.

- 200-question bank with reading, listening, images and recorded audio.
- Randomized attempts, saved progress, scoring and answer review.
- CBT and tablet-friendly UBT interfaces.

See [CBT-README.md](CBT-README.md) for setup, content attribution and maintenance.

Run `npm start` for a local preview or `npm test` to run the tests. The site can be hosted directly as a static website.
